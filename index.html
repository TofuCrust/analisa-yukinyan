Model AI: Mana yang Cocok untuk NekoSport?

NekoSport membutuhkan model AI untuk menganalisis data pertandingan dan menghasilkan perkiraan peluang. Pilihan model menentukan kualitas analisis, kecepatan, dan biaya. Berikut perbandingan tiga model yang tersedia.

PALING HEMAT
⚡

Haiku 4.5

Model tercepat dan termurah. Cocok untuk tugas sederhana seperti membaca data pertandingan, meringkas informasi, atau memformat hasil.

Input: $1.00 / MTok
Output: $5.00 / MTok
Untuk NekoSport: Membaca dan meringkas data standings, memformat data mentah menjadi ringkasan terstruktur.
✦ PILIHAN UTAMA
🧠

Sonnet 4.6

Keseimbangan optimal antara kecerdasan dan biaya. Mampu menganalisis banyak faktor pertandingan sekaligus dan menghasilkan perkiraan peluang yang terstruktur.

Input: $3.00 / MTok
Output: $15.00 / MTok
Kandidat utama NekoSport: Analisis data pertandingan — menimbang ranking, performa terkini, cedera, dan jadwal untuk menghasilkan perkiraan peluang dan alasan keputusan.
BELUM DIPERLUKAN
👑

Opus 4.7

Model paling canggih, tetapi paling mahal dan lambat. Tidak diperlukan untuk operasi rutin NekoSport saat ini.

Input: $5.00 / MTok
Output: $25.00 / MTok
Hanya untuk eksperimen atau perbandingan kualitas sesekali. Bukan untuk penggunaan harian.

Estimasi Biaya API — NekoSport

Biaya API dihitung dari dua hal: data yang dikirim ke AI (input) dan jawaban yang diterima dari AI (output). Gunakan tombol preset atau atur manual untuk melihat estimasi biaya bulanan.

Posisi Proyek Saat Ini

NekoSport sedang berada di tahap Intelligence Layer. Komponen adapter NBA sudah berjalan dan pengujiannya sudah lulus — termasuk mekanisme cadangan untuk sumber data standings. Namun, data performa pertandingan terbaru masih dalam penyempurnaan, sehingga kualitas data masih belum sepenuhnya lengkap dan tahap ini belum dinyatakan selesai. Estimasi biaya di bawah ini dihitung berdasarkan pola penggunaan yang direncanakan untuk fase ini.

Menjaga Efisiensi Penggunaan API

Biaya API bisa membengkak jika data yang dikirim ke AI tidak efisien. Berikut sumber pemborosan yang paling umum dan cara mengatasinya.

Komposisi Data dalam 1 Analisis

Seberapa besar porsi setiap bagian dari total data yang dikirim ke AI.

🚨

Data yang Dikirim Terlalu Banyak

Mengirim seluruh halaman standings mentah atau riwayat pertandingan lengkap akan memakan banyak biaya tanpa meningkatkan kualitas analisis.

Solusi: NekoSport sudah meringkas data pertandingan sebelum dikirim ke AI. Yang dikirim hanya intisarinya — ranking, performa terkini, status cedera, dan jadwal.

⚠️

Jawaban AI Sulit Dipakai Sistem

Jika AI menjawab dengan paragraf bebas, sistem tidak bisa membaca hasilnya secara otomatis dan harus meminta ulang (biaya 2×).

Solusi: AI diwajibkan menjawab dalam format terstruktur yang langsung bisa diproses: perkiraan peluang, alasan utama, dan faktor risiko.

💰

Salah Memilih Model

Memakai model paling mahal untuk tugas yang bisa dilakukan model lebih murah sama artinya dengan pemborosan langsung.

Solusi: Sonnet untuk analisis utama. Haiku untuk tugas ringan. Opus hanya untuk eksperimen.

💡

Cache Belum Dimanfaatkan

Setiap analisis selalu mengirim instruksi yang sama berulang kali — padahal instruksi ini tidak berubah antar pertandingan.

Solusi: Instruksi yang sama bisa disimpan (di-cache) sehingga hanya data pertandingan yang dikirim ulang. Hemat bisa signifikan setelah penggunaan stabil — tapi bukan diskon otomatis dari panggilan pertama.

Pertanyaan yang Mungkin Muncul

Model apa yang sebaiknya dipakai sekarang?

Sonnet 4.6 adalah pilihan utama untuk analisis pertandingan — keseimbangan terbaik antara kualitas dan biaya. Haiku 4.5 bisa dipakai sebagai pendukung untuk tugas ringan seperti meringkas data. Opus 4.7 belum diperlukan untuk fase saat ini karena biayanya jauh lebih tinggi tanpa manfaat tambahan yang sebanding untuk operasi rutin.

Berapa perkiraan budget awal yang masuk akal?

Mulai kecil dengan Sonnet 4.6 sebagai model utama. Dengan pola penggunaan saat ini (2 scan per hari, sekitar 15 kandidat per scan), estimasi biaya bulanan masih di kisaran belasan dolar — sangat terkendali. Tidak perlu menyiapkan budget besar di fase shadow mode. Biaya bisa ditinjau ulang saat penggunaan meningkat.

Kapan caching mulai layak diterapkan?

Caching paling efektif saat instruksi untuk AI sudah stabil dan tidak sering berubah — artinya template analisis sudah final dan pola penggunaan sudah berulang secara konsisten. Di tahap awal saat instruksi masih sering direvisi, manfaat cache belum optimal. Sebaiknya aktifkan caching setelah pola operasional harian sudah jelas dan stabil.

Proyek saat ini sudah sampai mana?

NekoSport sedang berada di tahap Intelligence Layer. Adapter NBA sudah berjalan dan pengujiannya sudah lulus, termasuk mekanisme cadangan untuk sumber data. Namun, data performa pertandingan terbaru masih dalam penyempurnaan sehingga tahap ini belum dinyatakan selesai. Sistem masih berjalan dalam mode pengamatan (shadow mode) — belum ada transaksi nyata.

Apakah biaya API saat ini masih wajar?

Ya. Dengan volume penggunaan fase shadow (sekitar 30–40 panggilan per hari), biaya API masih sangat rendah — di bawah $20/bulan untuk Sonnet, atau sekitar Rp250.000–330.000. Ini jauh di bawah biaya infrastruktur lainnya. Biaya API baru menjadi perhatian serius jika volume penggunaan naik signifikan (misalnya ratusan analisis per hari di semua cabang olahraga), dan saat itu caching akan sangat membantu menekan biaya.
